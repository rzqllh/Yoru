Mulai dari **[Panduan mulai](getting-started.md)** jika ini pertama kali menjalankan Yoru. Semua halaman ini menjelaskan **fitur yang sudah ada** pada web preview; bukan roadmap yang diperlakukan sebagai fitur aktif.

**Perlu diketahui:** Sumber video anime tidak otomatis tersedia; panduan urutan masih berbasis relasi langsung dan metadata torrent belum berarti video playable. Demo video dan subtitle Indonesia dapat dicoba melalui **Pengaturan → Coba pemutar** setelah aplikasi berjalan. Lihat [README utama](../../README.md) untuk status fitur dan penghargaan kepada proyek referensi.
